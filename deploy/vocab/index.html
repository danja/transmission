Transmission Vocabulary

http://purl.org/stuff/transmissions/, prefix trn:. 211 terms.

Terms for describing audio plugins and the graphs they run in: what a plugin is musically, the signals it accepts and produces, how nodes are routed, the actions an agent can ask a host to perform, and the shape of a DJ set list.

The machine-readable form is transmissions.ttl, which this page is generated from and which is what you get by asking for text/turtle.

A term IRI such as trn:PluginProfile answers 303 and redirects here, because the term denotes a class or a property and not this page.

Terms defined elsewhere. Some trn: IRIs in published data are not defined in this document: the plugin format individuals and the parameter terms are maintained in plugin-universe's vocabs/trn-extensions.ttl, and a few used by downspout are not yet declared anywhere. Which repository owns trn: is an open question rather than an oversight, and this page would rather say so than look complete.
