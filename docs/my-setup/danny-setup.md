# Danny Music Room

The heart of the setup is a computer with a Behringer UMC404HD audio interface plus several addition MIDI devices. There is an analog mixer, various real instruments (guitar, clarinet, baritone guitar, bass, microphones etc), and a small Eurorack setup.
