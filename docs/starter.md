# Original design brief

Transmission began as a proposal for a Linux VST3 host with graph-connected
audio and MIDI processing. The initial design called for a Node.js project
layer, a native real-time engine, and concepts adapted from the earlier
Transmissions data-processing framework.

That foundation is now implemented and has developed into a Generative Audio
Workstation with a native GTK editor, RDF Turtle projects, JACK/PipeWire
integration, offline rendering, plugin behaviour profiles, and MCP control.

See the current [architecture](architecture.md) and
[implementation plan](plan.md) for authoritative details.
